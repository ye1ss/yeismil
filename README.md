# yeismil.com

Portfolio of Yeismil del Rosario — full-stack developer in Madrid.

- Static site, no framework. English / Spanish, dark / light.
- Content lives in `content/projects.mjs`; run `node scripts/build.mjs` to regenerate the pages.
- Preview locally: `python3 -m http.server 5174` and open http://localhost:5174

See `CLAUDE.md` for architecture details.
